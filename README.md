# 小乔 · 时之魔女

一个运行在 Windows 桌面的 2.5D 陪伴桌宠，同时显示本机 AI 的工作状态。左边是坐在秋千上的小乔，右边是紧凑的 AI 工作台：看一眼就知道哪个 Agent 在做什么、处于什么阶段。

![当前小乔与 AI 工作台：左侧秋千角色，右侧展示 Agent 的阶段、任务方向与额度区域](docs/media/current-workspace.png)

*图片由当前生产合成器离线生成，工作流使用模拟数据，额度均为未知；“模拟”在界面内标注。这是静态布局预览，不是桌面截图或动态特效验收，也不代表 Claude 云端会话已接入。*

## 现在的桌宠

- 默认是半高工作台的实时视图；有记录的 Agent 各占一行，最多显示 Codex、Claude、ZCode 三行，点击名字或任务可展开记录。
- 工作流显示“阶段＋任务方向”，例如“编写与修改 · 工作流与进度”“委派子智能体 · 颜色与对比度”。读取文件、运行命令等细碎操作会合并。
- 小乔保留摸头、喂糖、聊天、休息与叫醒，帽发有小幅惯性，秋千接触位置保持稳定。休息时使用单条自然闭眼线。
- 帽上有星轨拖尾、思考星烟、少量萤火与符文；思考开始和结束会产生短暂反馈。素材预烘焙，粒子数量有上限。
- 工作台、聊天与右键弹层使用统一的深色半透明材质，文字清楚、下层桌面略可见；这是透明度合成，没有实时背景模糊。

主程序仍是 `pet.py`。`house3d/` 是保留的 Godot 独立实验，不是默认桌宠，也不是运行所需依赖。

## Windows 快速开始

使用 Windows 10/11 和带 Tkinter 的 Python；当前桌面版本在 Python 3.14 上验证。克隆默认分支即可取得当前整理版。

```powershell
git clone https://github.com/shuai9928/xiaoqiao-desktop-pet.git
cd xiaoqiao-desktop-pet
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe pet.py
```

不配置 AI 密钥，也能使用桌宠和读取已有工作状态。自由聊天需要另行安装 AI 依赖并配置服务，见[安装与使用](docs/GUIDE.md)。仓库不提供个人配置、真实会话或账号额度样本。

更新源码后，请先从桌宠菜单退出，再运行 `pet.py`。重复启动会唤起旧实例，不会给正在运行的进程重新加载代码。已有修改请先保存，不要用新目录覆盖个人存档。

## 基本操作

| 操作 | 当前作用 |
| --- | --- |
| 左键点击角色 | 摸头等轻互动；休息时可叫醒 |
| 按住拖动 | 移动角色工作台 |
| 角色／场景上滚轮 | 缩放；展开的工作流列表内滚轮用于浏览记录 |
| 双击角色或点“聊聊” | 打开聊天与对话记录 |
| 中键 | 打开 AI 工作信息 |
| 右键 | 打开互动卡片；“场景与设置”进入完整菜单 |
| 点击 Agent 名字／任务行 | 查看该来源的任务或已观察阶段；“收起”回到实时视图 |

声音、回复朗读、任务提醒、置顶、鼠标穿透和大小都在设置菜单中。完整说明见[使用指南](docs/GUIDE.md)。

## AI 工作台显示什么

会话状态和账户额度是两份独立数据：显示 Claude 的额度，并不等于已经连接 Claude 的某个会话。

| 来源 | 当前读取方式 |
| --- | --- |
| Windows 原生 Codex、Claude Code | 主程序启动本地日志采集线程，只输出经过清洗的公开工具活动与状态 |
| ZCode | 已配置的通知／会话 hook 写入本机快照 |
| WSL、Mac 会话 | 通过对应 hook 或同步桥接写入快照；需要使用者另外配置 |
| 额度 | 读取 AIQuota 的本机用量文件，或已有来源的额度快照；桌宠不凭空查询所有账号 |

“进行中”“等你确认”“遇到问题”“久未更新”按取得的数据显示。进度点表示已观察的阶段，不是百分比；子代理分工表示已经委派的方向，不代表代理完成，也不统计实际并行数量。没有数据时显示缺失，过期样本标旧；Claude 云端没有本地会话日志时不会被冒充为实时接入。

数据来源、聊天配置与本地文件边界见[AI 与数据说明](docs/ASSISTANT.md)。

## 仓库结构

```text

assets/               角色、场景、特效、声音与无密钥配置示例
tests/                单元、界面和隔离集成测试

house3d/              独立 Godot 实验
```

具体模块职责见[开发指南](docs/DEVELOPMENT.md)，全部文档入口见[文档导航](docs/README.md)。

## 检查与贡献

从仓库根目录运行：

```powershell
py tools/run_checks.py
py tools/check_docs.py
py tools/check_public_files.py
```

测试运行器使用临时副本，隔离配置、聊天、记忆与真实 AI。默认覆盖当前必需和定向测试以及 `test_pet`；`--unit-only` 用于 CI，`--legacy` 单独检查旧兼容行为，可能因退役功能断言失败。测试细节与视觉验收边界见[开发指南](docs/DEVELOPMENT.md)，提交方式见[参与贡献](CONTRIBUTING.md)。
