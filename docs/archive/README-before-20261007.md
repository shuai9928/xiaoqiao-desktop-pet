# 小乔 · 时之魔女

> **2026-10-06 ZCode 最新实装交接**：此分支包含本机 d9abf10 的工作台、A1/A2 与 B1～B5 帽上特效。云端继续开发请先读 [CLAUDE_HANDOFF.md](https://github.com/shuai9928/xiaoqiao-desktop-pet/blob/8cbbdc0ba9266e634e8957f2d7f4d9dfc08f7965/handoff/zcode-20261006/CLAUDE_HANDOFF.md)。下文保留历史说明；当前行为以根目录源码和交接文档为准。

Windows 桌宠，现在默认运行「核心陪伴版」。保留当前角色和秋千，让画面与操作集中。

- 日常：摸头、喂糖、休息/叫醒，少量表情与呼吸。
- 场景：默认「工作室」——她坐在一根钛金色弯管支架上，像产品照一样的软影，下方一枚黑色状态胶囊；
  也可在「场景」里换成 Live2.5D 魔女小屋。整体拖动、滚轮缩放。
  另有「3D 小屋（试验）」：Godot 真 3D 独立窗口（I-25），需本机 Godot 4。
- AI：聊天与已有对话记录、实际工作轨迹、额度、状态灯和可关闭的任务提醒。

右键打开四项互动卡片（聊天、喂糖、小屋、休息）。「场景与设置」进入精简菜单；
双击打开聊天，中键打开 AI 工作信息。小屋台座上的铭牌显示当前来源、状态、最新一步和 Claude 5 小时剩余额度；点铭牌在小屋旁打开 AI 工作书页（字号与聊天窗一致，随屏幕倍率放大）。独立秋千保留书、水晶与卷轴入口。

番茄钟、喝水/自定义定时提醒、天气、电量监控、猜拳/猜数字/占卜、唱歌、玩球、
跳舞/翻滚/变身/大型魔法、窗口观察、剪贴板/找文件/系统操作已退出当前版本。
对应自动触发、聊天动作、托盘、指令入口和重特效预热也已关闭。旧设置与历史数据
保留；没有删除个人文件，也没有提供日常「恢复所有功能」开关。

## 空间感

小屋桌面、窗框与椅架具有厚度和统一透视，地板有接触阴影；鼠标移动产生轻微视差。
角色使用连续网格：脸保持刚性，帽发有小幅滞后，坐垫/腿保持固定。
主秋千是完整的 2.5D：头部跟随视线（脸整体平移，头发、帽檐、帽尖依次更大的视差），帽子绕帽冠跟着次级物理弹簧摆、发梢滞后、胸口随秋千相位呼吸，受光随转头和荡近荡远移动；帽檐星轨（月亮/行星/水晶）绕新帽檐转，远侧被帽子挡住；地面有随摆动变化的软影；点帽子会抖帽子。绳、握绳的手、挂点、膝上的手、臀垫和腿脚恒为零位移。仍是原画上的 2.5D，未生成侧脸或背面。
小屋入口与道具同一投影；场景缩小时面板文字维持大小，目标至少32px。

小屋现在就是主桌宠场景（2026-10-04 第二版）：原来「左秋千 + 右常驻看板」太挡桌面、字太小，
改为单间小屋，人物居中，约 700×840（原 1180×810）。房子由 `tools/build_house_room.py` 从同一张
imagegen 原画派生：镜像左室得到对称的尖拱窗与两侧帘幔，修补月亮与屋顶月牙徽，再拆成两层——
前景框（屋檐、帘幔垂饰、帘子、立柱、台座）和室内（天花、侧墙、后墙窗、地板，带盒式深度图）。
秋千横杆藏在檐下帘幔后，绳子从帘后垂下，像挂在天花上；帘与柱真的挡在秋千前面。鼠标移动时
以秋千为静止面：前景框反向平移、后墙同向平移、地板/侧墙/天花按深度连续错切，室内被前景框
挡住的边缘预先补了一圈并烘焙了框的接触阴影。地板上有随摆动变化的影子。
铭牌与书页复用现有真实会话和额度快照；Claude 额度注明是共享账户，未知不显示为 0 或 100，
过期标「旧」。极小工作区（约 900×490 以下）临时退回秋千与展开书页，保留小屋偏好。

房间是活的，但很安静（`room_life.py`）：窗里星光明灭、月晕慢慢呼吸，月光里有浮尘，架上水晶球
微微发光，前面的水晶垂饰偶尔闪过一道光。她打盹时整间屋子约一秒半暗下来、她本人不变，醒来再亮回去。
铭牌上的宝石就是状态灯：运行时呼吸、等你确认时脉动、出错时发红光、刚完成时闪一会儿再安静；
鼠标移到铭牌上那一块会亮起并变成手形。系统「减少动画」时这些动效都不画。

## 界面材质

2026-10-04 先用 imagegen 生成设计稿，再统一功能界面。保留深紫、暖白、少量金色与书签，
参考苹果的留白、圆角与信息层级。控制卡、聊天、工作书页和提示使用 `ui3d.py` 的 calm 材质，
取消四角金钉、厚重凹槽与大面积光效。按尺寸缓存绘制，不是苹果原生玻璃 API。

书或水晶打开人物侧边的 AI 书页，字号不跟随场景缩放；来源显示全称，概览与工作轨迹分组。
额度显示账户口径、周期、剩余/已用与缺失/过期/估算说明；运行紫、确认橙、错误红、完成绿。
轨迹有连续分页，点「全文」可滚动阅读完整可取得内容、选择与复制，Esc 先回轨迹再收书。
书页可拖动，跟随屏幕工作区钳制；隐藏或退出主桌宠会同步收书。聊天历史和阅读位置保留。

## 聊天

聊天窗在场景空的一侧打开。记录按轮次排版：每轮只写一次名字和时间，她的话靠左、你的话靠右，
日期居中分隔；她连着说同一句（比如旧提醒）只显示一次并计数 ×N，你的话从不合并。
等她回复时末尾有一行「小乔正在想 · · ·」，回复到了就消失。聊天记录文件本身不改动。

## 启动

使用原来的启动方式运行 pet.py。已经运行的桌宠要先通过菜单退出，再启动才能加载改动；
重复启动会唤起旧实例。不要使用旧的批量杀 Python 的重启脚本。
桌宠「场景 → 小屋 · Live2.5D」进入完整小屋；「秋千」返回单场景。旧「查看小屋样稿.bat」仅供查看历史桌椅样稿。

开发运行：`py pet.py`。需要 Pillow，托盘可选 pystray；AI 仅在主动聊天时按原连接使用。
`py pet.py --debug-state` 可写状态文件（含当前聊天内容，默认关闭）。

## 质感版（2026-10-04）

参考苹果的设计语言做了减法：舞台只用一种材质（钛金色弯管、柔和地影），界面统一深色石墨、
白色细边和系统色（紫=运行、橙=等你确认、红=出错、绿=完成/额度充足、蓝=操作），字体 Noto Sans SC。
状态胶囊：左边是动态状态符号、来源与状态、最新一步（点开工作流），右边的环是 5 小时额度（点开额度）。
聊天是「信息」式气泡，书页和右键卡片同一套材质。原画小屋、金饰横杆仍在素材里，可随时切回。




## 半高 AI 工作台（2026-10-05）
半高界面左侧保留魔女桌宠，右侧直接显示六条最近取得的具体动作。行首状态灯区分完成、运行、等待或错误；列表支持滚动查看更早记录。下方分别显示 Codex/Claude/ZCode 等 agent 会话状态与 Codex、Claude 的额度快照（含 Codex WSL）。缺失或过期的数据照实标注，不补造步骤、完成数或额度。
