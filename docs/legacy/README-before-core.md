# 小乔 · 时之魔女 — 桌面宠物

二次元魔法少女桌宠(Windows)。Python + Tkinter + Win32 分层窗口实现,
带 AI 聊天、提醒、番茄钟、找文件等桌面助手能力,以及一套完整的角色音效。

## 运行

```bash
py pet.py            # 直接跑(需要 PIL / pystray;AI 聊天另需 assets/ai_config.json 里的密钥)
py pet.py --selftest # 启动 3.2 秒自检后退出,输出 SELFTEST_OK,用于回归验证
py pet.py --debug-state # 额外每秒写 pet_state.json(默认关闭:它会把聊天框全文
                        # dump 到硬盘,开一天就是几万次写入)
```

单实例保护:已经有一只在跑时,再次启动只会把旧窗口带到前台。

## 音效系统(pet.py 内 SFX 类)

- 素材在 `assets/audio/`:42 条角色语音(Edge TTS「晓晓」预渲染)+ 6 条
  魔法闪烁(OpenGameArt CC0)。来源与许可证见 `assets/audio/CREDITS.md`。
- 播放走 winmm MCI(waveaudio),和唱歌(song.mp3)同一套 `mci()` 通道。
- 规则:**最多每 5 秒出一次声**(全局);同一槽位最新胜出;每个行为有
  独立冷却;变体随机挑选;失败静默跳过,绝不影响动画。
- 开关:`sound_on` = 语音总开关(音效+朗读一起),`tts_on` = 只管朗读,
  都在右键菜单「设置 ▸」和托盘里,持久化到 pet_settings.json。
- 聊天朗读:`_speak()` 优先用 edge-tts 实时合成(缓存到 `_tts_cache/`),
  失败(无 venv/断网)退回系统 SAPI + SSML 抬调。
- 改台词/换声线:改 `_sfx_dl/gen_voice_tts*.py` 的 CLIPS 表重跑,
  文件名不变、代码零改动。

## 动画系统

轻互动新增三段短动画:鼠标靠近时歪头回应,普通摸头时向光标方向轻蹭,
挠痒时左右笑抖后逐渐收势。连续点击从当前姿势接续;拖动、睡眠、唱歌、
思考和大动作优先,不会叠加轻互动变形。待机采用平滑的双节奏浮动。
鼠标静止在旁边不再定时重复触发靠近询问,回归问候也要求鼠标实际靠近。
这些变化不新增音效、存档字段或依赖;修改后退出桌宠并重新运行 `py pet.py` 生效。
轻互动的无窗口回归测试: `py -m unittest test_micro_motion -v`。

## 生命感次级物理

`life.py` 管的是"身上松垮的部分晚一点才跟上来":帽尖绕帽基微旋转、
发梢/裙摆下缘水平拖尾。激励源 = 呼吸速度反相耦合、水平加速度(拖拽/
抛掷)、落地冲击(fy 速度骤停自动检测,单次触发)、走路落脚上升沿、
四路不可通约频率的"微风"(永不精确循环)。spring 输出量化后进 warp
缓存键(旋转 1/100、位移 0.5px —— 肉眼不可见的台阶),静止时缓存几乎
总是命中。blocked 状态(翻转/滚动/变身等)衰减到 0,恢复 0.3s 缓入。
总开关 `PET_SWAY`(性能回退用)。测试: `py -m unittest test_life -v`。

## 魔女秋千(默认的家)

扫把已经从立绘上擦掉(`erase_broom.py`,原画备份 `assets/main.orig.png`),
换成了从显示器顶边垂下来的**月牙星链秋千**:紫→金渐变星珠链 + 金色月牙
座椅(两角坠紫晶星铃)+ 锚点缓旋小法阵。**默认 `swing_home = True`:
开机 2 秒后她自动入座,落地 idle 一阵后也会自己飘回去**;设置 ▸
「默认住在秋千上」可关。

- **物理是可积钟摆**(`life.Pendulum`):θ'' = -k·sinθ - c·θ'。静止时
  "泵"到 ±4° 微摆;点击她 = 推一下;**按住她拉 = 拉开秋千**(θ 跟手,
  限 ±0.8 rad),松手以放手瞬间的角速度回摆,十几秒衰减回微摆。长期没
  人理她还会自己荡大一点。摆过最低点轻微 squash,身体随摆角微倾。
- 「从秋千上下来」= 她从当前位置自然跳下落地(不瞬移);之后的动作
  (跳舞等)也是从弧线位置落下。落回地面 idle 一阵后自动回座。
- 绳椅画在独立穿透分层窗口(`SwingLayer`,z 序插在主窗口正下方),
  **窗口宽度随摆幅动态伸缩**(常驻 ~500px 窄条,拉远才展宽 —— 推帧
  成本差 4 倍)。荡着时 20fps,拉拽互动 60fps。
- **坑:这种窗口绝不能碰 Tk 的 `-alpha`** —— 那会切到
  SetLayeredWindowAttributes 模式,之后 UpdateLayeredWindow 永远静默失败
  (绳子上不了屏,而且不报错);防灰闪的正确姿势是先推帧、后 deiconify。
  另外 PIL 的 fill 墨色不接受浮点数(alpha 算出小数会整帧 TypeError)。
- 座下软影随摆速变化;测试: `py -m unittest test_swing -v`。
- **膝弯剪切**:小腿绕膝延迟弯折 —— 摆动减速/落地时小腿后甩(`life.knee_l/r` 弹簧 → 深度网格 `leg_bend` 剪切通道,膝线以下渐增位移),长期没人理时偶尔屈膝晃脚。
- **眼睑情绪**:角色没有可见眉毛(刘海遮盖),情绪走**眼睑开合度**——生气半眯 0.42、困倦耷拉 0.55、惊讶瞪圆 0.02,由 play_emotion 按类别驱动(复用眨眼肤色贴片贴上部 + 睑缘线);被拎着时也会眯眼。

## 秋千原画场景(2026-10-03 起的形象)

形象换成了 `assets/scene_src.png` 这张原画:她坐在月牙横杆的紫色坐垫秋千上,
左边魔法书、右边水晶灯。`make_scene_layers.py` 把它拆成 `assets/scene/` 下四层
(原画 1254×1254 画布坐标):

| 层 | 内容 | 运行时 |
|---|---|---|
| `static` | 横杆、两端金月牙与垂饰、中央宝饰、挂环 | 固定 |
| `swing` | 两根吊绳 + 坐垫 + 她 | 前后荡:挂点线以上不动,越往下越吃摆角(座椅随 cosθ 抬高、按透视变大/变小),手一直握在绳上 |
| `book` | 魔法书 | 固定;点击开 AI 轨迹书(和以前的小书同一入口) |
| `crystal` | 水晶灯 | 固定;身后/宝石上叠 AI 状态色(运行中慢呼吸),金环外缘画额度弧,其他来源待处理亮角标,悬停 0.35s 出提示 |

- 坐在秋千上时整个场景是**一个分层窗口**(主窗口本体):横杆、绳、书、水晶都
  能点、能拖;程序画的横杆/绳/座椅后景层(`SwingLayer`)不再使用。
- 她本人直接来自原画,眨眼/情绪眼睑/情绪嘴/唱歌嘴照常有:在立绘上画五官,
  只把画了以后变了的像素贴回原画(`_art_face_overlay`)。气泡、AI 灯板、
  粒子、卷轴仍由渲染帧画,整帧映射到原画里她的位置(`_art_small_map`)。
- **滚轮缩放整个场景**(0.6~1.8,持久化;原来滚轮缩放被"顺毛"的绑定覆盖,
  一直没生效)。离开秋千时滚轮还是顺毛。场景位置按中心存,换尺寸不跑位。
- 离开秋千时用 `assets/main.png`:同一张原画去掉吊绳、补好袖子/指缝的她,
  **坐着自己的魔法坐垫飘着走**。眼/嘴/帽檐星轨/部位网格(`rig`)/点击分区
  (按部位多边形判:帽子/摸头/挠痒)/托盘图标都在 `assets/config.json`。
- 素材缺失(没有 `assets/scene/meta.json`)时自动退回程序画的秋千;
  `PET_SCENE_ART = False` 也可以强制退回。
- 旧立绘配套的两只小动物(decors)画风不搭,`config.json` 里 `decors=false`
  关掉了;表情贴纸 `assets/expr/*.png` 还是旧画风,暂时保留。
- 换原画:替换 `assets/scene_src.png` 后要重新量 `make_scene_layers.py` 顶部的
  几何常量(横杆上下沿、挂点、帽尖列、书的边界、吊绳星饰/金链框)和
  `config.json` 的眼嘴/rig,再跑一遍脚本,看一眼 `py pet.py --selftest` 生成的
  `_preview_idle.png`(坐在秋千上时它存的是整张场景)。
- 测试:`py -m unittest test_scene_art -v`。

## 分层渲染(Live2D 式)

> **2026-10-03:换成秋千原画后,旧立绘的腿层也已归档(`_archive/2026-10-03_换新立绘前/`),当前没有任何分层图层。** 下面是旧立绘时期的记录。
>
> **现状(2026-10-02):只启用腿层;帽层、发层停用。**
> - **帽层/发层**:自动切出来的是坏图 ——「帽层」里其实是刘海+眼睛(帽子留在底图),发层带着一只眼睛和直角矩形边。叠在完整底图上,一摆动眼睛就会跟着帽子飘走。坏图层在 `_archive/2026-10-01_自动切层回退/`;`cut_hat.py` / `cut_hair.py` 已加闸,默认拒绝运行(10-01 下午就是被重跑后原样复发的)。帽尖/发梢的摆动仍由底图的深度网格完成。
> - **腿层**(`cut_legs2.py`):内容是对的,但之前**一直没画出来**,腰下是一块透明洞。原因在 `DepthWarp.warp(source_offset=...)`:① 只平移了输出框、没平移采样四边形;② 跳空格用底图的覆盖表,而腿层恰好在底图被挖空的地方,整层被滤光;③ Pillow 裁剪越过左/上边界的网格框时会整格错位。三处都修了(画布原点对齐网格线),`test_depth` 加了回归用例。另外腿层现在比挖空范围多出 8px 重叠(仅不透明像素),踢腿时不露缝,静止合成也没有半透明接缝;腿层缓存键补上了膝弯。
> - 启用新图层前务必看一眼 `py pet.py --selftest` 生成的 `_preview_idle.png`。

渲染顺序:底图(无帽无发的身体+脸+发穹顶)→ **发层**(剪切摆动:发梢位移大、锚定肩线处为 0,与底图拼接无接缝)→ **帽层**(大幅弹性摆动:呼吸反相/微风/步伐/落地/拖拽/摆动角加速度全部驱动)。两层共用底图的深度网格(lean/squash/视线完全同步),通过 `warp(source_offset=...)` 支持裁剪坐标。发/帽层摆幅:静止微风 ±2px、拉拽/落地 ±14px。缺图层时自动退化为单贴图。测试: `test_life` / `test_swing`。
发层进一步**三分带**(左/中/右缕,羽化重叠 4%):每缕独立弹簧(2.35/2.65/3.05Hz)+ 独立微风相位 —— 相位差让头发呈波浪般起伏;摆动/落地的冲量经 `impulse_hair` 按 1.0/0.82/0.66 递减传给三缕(外缕滞后更多)。
- **呼吸体积场**:胸/肩随呼吸相位局部扩张(与整体浮动错相,幅度 `_breath_amp`),网格身体区加密 18×24;**micro-saccade**:每 2~4.5s 眼球小幅跳动(10% 连跳);**绳垂弧**:静止下垂、快摆绷直;**月牙弹性**:过最低点座面压缩 4% 回弹。全部量化进缓存键,安静档 20fps 不变。

## AI 会话灯

Mac 触控栏会话灯的桌面版:她身侧一列小光球,**橙=等你批准、红=出错、
紫=在跑、绿=刚完成(90 秒后转空心)、空心=空闲**。数据在 `ai_sessions/`
(一个会话一个 JSON),三个来源,全家的 AI 都在灯上:

- 本机 ZCode:`zcode_notify.py` 挂 SessionStart/UserPromptSubmit(紫=
  running)、Stop(绿=done)、PermissionRequest(橙=waiting);
- WSL Codex(含 Windows Codex 桌面 app 的代理,它就跑在 WSL 里):
  `~/.local/bin/xiaoqiao-lights-hook.py` 同样四态,经 /mnt/c 直写;
  Codex 的 hook 改了命令要在 WSL 里重新信任(`wsl_codex_trust.py`);
- Mac(Claude + Codex):`mac_session_sync.py --loop` 每 2 分钟拉
  AIQuota 的 `sessions/*.json`(`mac-<会话id>.json`,Mac 离线就安静等)。

防呆:done 亮 90 秒转空心;running 40 分钟没任何更新也按熄掉算(进程
硬崩溃没人写 done);zcode-/wslcodex- 灯各留最新 8 个,旧的自动清。

本机会话的变化由 hook 播报,不重复说;**Mac 会话状态变化她会开口提醒**
(同类 120 秒限频、全局 40 秒一句、睡着不打扰)。设置 ▸「AI 会话灯」
可关。回归测试: `py -m unittest test_session_lights -v`。

## 专注陪伴模式

番茄钟原来只是个计时器:专注期间她照常闲聊、走动、打喷嚏、主动搭话,
75 秒没人碰还会直接睡过去 —— 和"陪你专注"的承诺正好相反。

现在"专注"段她会安静下来:

- **抑制**:闲聊/走动/贴纸/哼歌/吹泡泡/打喷嚏/追光标/跳舞/探头(整条
  idle 事件流)、AI 主动搭话、被冷落撒娇、流星许愿台词、自动入睡
- **保留**:呼吸、眨眼、视线跟随、脚下法阵微光;夜间流星本身也留着 ——
  无声划过是"窗外的夜在继续",不算打扰
- **加入**:每 4~7 分钟无声地冒几点星光;过半时轻蹭一下
- **摸她照常有反应**,只是气泡时长被压到 2.2 秒以内(提醒和 AI 回答走
  `keep=True`,不受此限 —— 那是你自己要的内容)
- **休息段恢复原样**,开场一起伸个懒腰

关键约束:陪伴演出只用 `AMBIENT_PARTS` 里的粒子(`sparkle`)。`heart` /
`confetti` 这类会把省电的 20fps 安静档顶成 60fps 并持续整个粒子寿命 ——
`test_focus.py` 有一条用例专门钉住这点。

实测(真 tick、光标挪远模拟在别处敲键盘):专注期间 430/454 帧落在 20fps
安静档,状态全程只有 `idle`,一句话都不说;同样处境下不开专注,她会说 3 句
并睡过去。`--debug-state` 写出的 `pet_state.json` 里新增了 `focus` 字段,
配合已有的 `frame_delay` / `quiet_block` 可以随时复核。

专注陪伴的回归测试: `py -m unittest test_focus -v`(壳桌宠,不建窗口、
不碰存档)。

其他动作精修:挥手随节拍轻摆,星光沿抬起的手划出短轨迹;后空翻按实际
时间计算抛物线,落地时同步压缩回弹、冲击波与星光。变身新增前后分层的
螺旋星带,前层避开脸部;冲击波扩散时逐渐变淡,弱冲击也能完整淡出。
动作与特效回归: `py -m unittest test_action_fx -v`。

舞蹈的小跳、落地光圈和谢幕现在由同一拍点驱动,谢幕落地后才庆祝。
碎步与打滚采用按时间计算的位移,不再随帧率改变距离;打滚的转向与移动
方向一致。伸懒腰改为缓慢舒展与轻回弹。拖动会中断这几组动作。
打滚时按可见轮廓贴地,旋转贴图的透明留白不会把角色抬到半空。
法阵能量只改变旋转速度,亮度变化时不会突然跳转角度。

日常动作:星光糖沿弧线送到嘴边,入口后消失,接上轻咀嚼和满足点头;
短星光拖尾与糖果使用同一条轨迹。哈欠先舒展再缓缓低头入睡;
睡醒先抬头回神,清掉残留 Zzz,仍然空闲时才接伸懒腰,新互动会取消预约。
睡眠夜色使用透明叠加,保留角色细节与不透明度,避免整只暗到几乎消失。

走神惊醒:短暂点头后轻跳,落地才触发星光冲击,支持拖动打断。
聊天窗:分层标题、快捷摸头/喂糖/挥手、记录滚动条与输入反馈,适配小屏。
阅读旧消息时新回复不抢滚动位置;右键菜单把喂糖与睡觉/叫醒放在一级。
界面回归: `py -m unittest test_chat_ui -v`(模拟桌宠,不访问 AI 或个人存档)。

### 精致灵动升级

右键小乔打开互动卡片:顶部显示陪伴天数、好感与星光条,六个按钮提供聊天、
喂糖、时间魔法、跳舞、玩球、睡觉/叫醒。「更多」保留完整菜单(含设置、
退出)。Esc 或点击其他窗口可收起;Tab 切换按钮、Enter 执行。卡片按当前
显示器工作区定位,支持左侧副屏和任务栏边界。

拖拽按最近 120ms 的实际速度轻倾与撒星尘,停住后柔和回正,松手不沿用
陈旧速度误抛。追随在发出命令时确定目的地,平滑起步与减速,最多持续 6 秒。
光球在脚下基线反弹、五秒后消失,点击光球会接住并点头;绘制、命中和物理
共用坐标。再次玩球替换旧球,拖动或入睡取消本轮。气泡改为暗紫星金配色,
120ms 淡入、180ms 淡出,底图和文字排版缓存复用。

表情续接:同一类表情连续触发时保留贴纸与当前尺寸,只延长停留时间;
不同表情以 180ms 过渡,快速切换最多保留两层,到期完整淡出。贴纸以一次
透明合成叠加,避免淡出时额外变暗。互动卡片悬停或键盘选中按钮会显示操作
提示;正在吃糖、施法或尚未落地时,暂不可用的操作显示原因并自动恢复。

喷嚏先两次轻吸气,再前倾、回弹并站稳,星光在身体侧下方短暂散开。
眩晕从当前姿势渐入,摇摆逐渐减弱,侧边六颗星光避开脸部;脚滑后短暂停顿,
接站起和轻回弹,脚下只出现一次小光圈。三组动作按经过时间推进,10/30/60fps
节奏一致;拖动取消喷嚏与站起,卡顿后不补放已经过时的喷嚏特效。

### 自然立体感

保留原画,以脸、头发、帽子、身体、衣裙和扫帚的连续深度网格实现轻微转头。
左右等效角度上限 8°、上下 4°;头部、身体、发梢分别以约 120/200/260ms
跟随,帽沿与发梢稍晚收势。边框、小动物和装饰星不参与人物的额外视差。
这仍是小角度 2.5D 演出,不会生成原图中没有的侧脸或背面。

左上柔光随转头轻微变化,脸部明暗限制在 4% 内,其他部位在 8% 内;
脚下增加随腾空变淡、变宽的柔影。眨眼、睡眼与嘴巴先绘制到人物局部,
再一起变形和旋转,嘴部位置与原画嘴巴对齐。
拖拽时降低转头幅度,睡眠缓缓回正;空翻、打滚、快速旋转和飞行时暂缓
附加视差,结束后 250ms 恢复。极端动作叠加有网格防翻折保护。

视觉参数在 `depth_model.py`,不写入个人存档。网格缓存最多 12 张、光照
最多 2 张、阴影最多 13 档,缩放时重建。透明区域跳过重采样,细发丝与
半透明边缘保留;沿用 Tkinter/PIL,不增加依赖。

动作 = 一张声明式时间轴表(`start_*` 里挂载,状态分支只留一行
`_play_timeline`):参数轨道(squash/lean/bend/spin_rot…)按关键帧
smoothstep 插值,一次性事件到点触发音效/台词/粒子,程序性节奏(节拍器、
微颤)留在分支里。变形维度:look/lean/squash(网格) + bend(侧向弓身) +
spin_rot(整只平面旋转/后空翻) + 残影拖尾 + 落地冲击波 + 表情嘴。
加新动作 = 填一张表 + 一个 start_*。

## 调试/自动化接口

写 `pet_cmd.json`(单条 JSON,按 mtime 触发)即可驱动:

```json
{"op": "pet"}          {"op": "dance"}       {"op": "dizzy"}
{"op": "throw", "vx": 800, "vy": -600}
{"op": "play_sfx", "name": "greet"}   {"op": "toggle_sound"}
{"op": "announce", "text": "...", "emotion": "happy"}
{"op": "remind", "minutes": 5, "text": "..."}
```

全部 op 见 `pet.py` 的 `_exec_cmd`。状态输出在 `pet_state.json`。
