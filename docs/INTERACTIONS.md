# 小乔 · 互动图解手册

[← 文档导航](README.md) · [安装](GUIDE.md) · [完整菜单](../README.md#menus) · [聊天助手](ASSISTANT.md)

这份手册按“从哪里进入 → 怎么操作 → 会看到什么 → 什么情况下不会触发”说明功能。先启动小乔；没有 AI 密钥也能完成下面的角色互动、小游戏和计时提醒。

## 1. 先认清几个入口

![右键卡片、完整菜单、聊天指令与托盘入口地图](media/menu-map.svg)

**右键小乔**打开六按钮互动卡片；点卡片底部的**更多**，进入完整菜单。每次只打开一张卡片，点完一个动作后会收起；点击别处或按 Esc 也会关闭。键盘可用 Tab 切换、Enter 执行。

部分动作有状态限制。例如正在吃糖或施法时，不能立即再次喂糖。按钮暂时不可用时，提示区会告诉你原因；等当前动作结束，再试一次即可。

<p align="center"><img src="media/interaction-card-current.png" alt="当前源码的真实互动卡片：顶部星光与好感，中间今日小结，下方六按钮和更多入口" width="320"></p>

*当前源码的真实 Tk 控件截图。12 天、76% 星光和今日计数均为虚构样本；顶部 Windows 标题栏仅为截图预览容器，日常卡片不带该标题栏。*

| 卡片区域 | 怎么理解 |
| --- | --- |
| 名称和陪伴天数 | 角色身份及本机累计陪伴天数 |
| 星光百分比和进度条 | 当前星光能量，最高 100；会随运行消耗 |
| 好感称呼 | 关系进度，与星光能量是不同指标 |
| “今天”提示 | 按固定顺序显示前三个非零计数；鼠标悬停按钮时临时换成动作提示 |
| 睡觉／叫醒 | 根据当前是否睡眠或打哈欠切换文字 |
| 更多／关闭 | 进入完整菜单，或只关闭这张卡片 |

## 2. 用鼠标和她熟悉起来

![实际渲染的摸头、粉色光环、喂糖与星光反馈](media/feedback.webp)

*源码离线演示。隐藏随机台词和贴纸，以便看清动作；背景和左侧文字是发布排版。*

| 操作 | 手上的步骤 | 画面中的反馈 |
| --- | --- | --- |
| 摸头 | 左键点头部后松开 | 点击处出现粉色光环；她轻蹭、抬眼或回应，关系和彩蛋会影响台词 |
| 挠痒 | 左键点身体 | 金色命中光环、笑抖和逐渐收势 |
| 顺毛 | 在角色上滚动鼠标滚轮 | 触发顺毛互动 |
| 小惊喜 | 点击鼠标中键 | 从多种动作中随机选一种，包含浮空冥想 |
| 时间魔法 | 双击角色 | 播放当前默认风格的时间魔法 |
| 提起与移动 | 按住并拖动 | 开始抓取时亮一圈；移动速度影响倾斜与星尘，停下柔和回正 |
| 甩出去 | 快速拖动后松开 | 抛飞、沿路径留下星尘、下落与落地反馈；停住再松手不会沿用旧速度 |
| 靠近观察 | 移动光标靠近她 | 轻微转头与部位跟随；脚下法阵逐渐变亮、符文转快，初次靠近荡出欢迎光纹 |

静止鼠标不需要一直触发互动。待机时的呼吸和法阵光纹会自行缓慢变化；睡着时脚下法阵与光纹收起。转头是保留原画的小角度 2.5D 变形，并没有额外的侧面或背面模型。

### 喂一颗星光糖

1. 右键 → **喂糖**，或聊天窗顶部 → **喂颗糖**。
2. 等糖果沿弧线送到嘴边，接上咀嚼、糖屑和满足点头。
3. 看头顶的星光飘字与卡片进度条。飘字显示实际增加的整数值：例如原来约 90，补到上限时显示约 +10；已经满格不会再飘奖励数字。

角色正在空中或进行不兼容动作时，先等她落地或结束动作。今日“喂糖”统计记录接受的喂糖互动，不是点击被拒绝的次数。

## 3. 新动作：浮空冥想

![浮空冥想实际演示：蓄力升空、星核环绕、缓慢落地](media/meditation.webp)

最直接的入口是**打开聊天窗，输入“冥想”**。也可以说“飘起来”或“浮空”；中键随机惊喜也可能选到这个动作。当前“一起玩”子菜单没有独立的冥想按钮。

| 时间段（约） | 动作 | 看点 |
| --- | --- | --- |
| 0–1.2 秒 | 小幅蓄力后升空 | 从地面平滑抬起，不突然跳到空中 |
| 1.2–4.3 秒 | 悬停、轻微起伏 | 三颗发光星核绕行；近侧较亮，远侧被角色遮挡，尾迹在远处较小 |
| 4.3–5.6 秒 | 收势并落地 | 星核淡出，接上轻压缩、星光和一次落地回应 |

睡着时会先尝试叫醒；在不兼容的忙碌状态下不会强行切入。冥想是一段短动作，不是启动长时间计时器，也不是番茄钟的另一个名称。

## 4. 四种小游戏，分别怎么玩

### 接光球

![拖动与光球互动演示](media/play.webp)

1. 卡片 → **玩球**，或更多 → 一起玩 → **玩球（扔给她接！）**。
2. 在光球出现后的约 5 秒内，直接点击球体。球会沿脚下基线弹跳，并带短拖尾和落地光圈。
3. 命中后球立即消失，小乔接住、点头并给星光反馈。连续点同一个球只结算一次。

只保留一颗球。再次开始会替换旧球；拖动角色或让她睡觉会取消当前球；超时后球自动结束。

### 接星星

入口：更多 → 一起玩 → **撒一把星星（点星接住！）**。点击飞出的可接星星，命中会亮金色光环；连续接中有连击反馈，结算与最高纪录由程序记录。装饰星、原画上的星星和背景粒子并不都是可点击目标。

### 石头剪刀布

入口：更多 → 一起玩 → **石头剪刀布** → 选择石头、剪刀或布。等她出拳并公布结果。同一子菜单底部显示的是**她的胜／平／负**，读成绩时别把双方方向看反。

### 猜数字

在聊天窗输入**猜数字**开始 1–50 的游戏，再输入数字。小乔会提示“大了”或“小了”，猜中后给反馈。想提前结束，可以说**不玩了**。

**今日运势**也是聊天入口，属于娱乐彩蛋；不作为现实预测或决策依据。

## 5. 魔法与动作菜单怎么选

| 想看什么 | 入口 | 使用细节 |
| --- | --- | --- |
| 角色周围的时间魔法 | 更多 → 时间魔法 → 原版 | 适合看局部的法阵与星光 |
| 更大范围的演出 | 更多 → 时间魔法 → 全屏炫酷版 | 在更大画布播放特效；首次素材预热可能影响启动时机 |
| 把炫酷版设为日常默认 | 同一菜单 → 默认使用炫酷版 | 卡片“时间魔法”和双击会使用此默认设置 |
| 临时星光形态 | 更多 → 一起玩 → 魔法变身 | 变身动作后保留约 30 秒星光形态 |
| 时间停住的演出 | 更多 → 一起玩 → 时停 | 表盘、齿轮等视觉反馈；不会暂停其他软件或系统时钟 |
| 时间回溯的演出 | 更多 → 一起玩 → 时间回溯 | 倒转的视觉与角色动作；不会撤销文件或恢复电脑操作 |
| 走到你指定的位置 | 更多 → 一起玩 → 过来我这边 | 目标是命令发出那一刻的鼠标位置；最多约 6 秒，拖动可以打断 |

其他动作包括转圈、跳舞、后空翻、打滚、挥手、伸懒腰和发呆。挥手有四拍轻摆与踮脚；移动会按步伐落星尘；落地光圈和动作拍点同步。所有菜单原文见[完整菜单表](../README.md#menus)。

## 6. 把一段专注交给她陪

![番茄钟、安静陪伴、休息与今日小结的完整流程](media/focus-flow.svg)

1. 更多 → 小本事 → **番茄钟** → 专注 25 分钟或专注 50 分钟。
2. 专注段中，她减少主动打扰，保留呼吸、眨眼、视线和少量星光。主动摸她仍会有回应；你请求的提醒或 AI 回复不会因专注被吞掉。
3. 专注完成后进入 **5 分钟休息**，增加完成次数、好感和今日专注分钟；休息结束再提醒一次，本轮随后结束。

提前结束用同一子菜单的**停止番茄钟**。今日分钟数在专注完成时加上本段时长，并不是实时累计屏幕使用时间；提前停止不按零散分钟结算。

**喝水提醒独立设置**：更多 → 小本事 → 喝水提醒 → 关／每 30／45／60／90 分钟。它和一次性提醒、番茄钟可以同时存在。程序退出或电脑关机期间无法实时通知。

## 7. 她会注意到笔记本的电量

![使用模拟插电事件生成的实际充能特效](media/charging.webp)

*插电事件由隔离演示脚本模拟，没有读取或改变你的真实电源状态。*

入口：更多 → 设置 → **电量提醒：开／关**。程序约每分钟采样一次 Windows 电池状态；没有可用电池数据的台式机不触发这组互动。第一次读取只建立基线，不会补报此前发生的事情。

| 变化 | 她的反应 | 条件 |
| --- | --- | --- |
| 从未插电变为插电 | 充能星光、光圈与回应 | 星光奖励最多每 10 分钟一次，每次至多 +5，仍受 100 上限限制 |
| 拔掉电源 | 提醒省着点用 | 检测到插电状态发生变化时 |
| 未插电，电量从高于 20% 降到 20% 或更低 | 困倦提醒 | 跨过阈值时触发，停留在低电量不会每分钟重复说 |
| 未插电，从高于 10% 降到 10% 或更低 | 更急切的找充电器提醒 | 同样按阈值跨越判断 |
| 插电中，从未满到 100% | 充满庆祝 | 充满变化时触发 |

专注中、睡觉或打哈欠时不打扰，也不会等你醒来再补播积攒的电量事件。采样间隔决定它不是即时系统电量报警的替代品；只展示提醒，不调整 Windows 电源计划。

## 8. 今日小结和好感怎么读

统计项依次为：**摸头、喂糖、接星、完成的专注分钟、聊天、挠痒**。卡片最多显示前三个非零项；没有数据时显示普通陪伴提示。非零项按固定顺序选取，不是最近三次动作，也不是数值排行榜。

数据按本机日期重新计数，有改动时最多每分钟保存一次，正常退出也会保存。晚上 **21 点后**，在空闲、无气泡、没有拖动、不处于专注且距上次互动超过约 20 秒时，她会尝试总结当天一次。它不是每日 21:00 准点闹钟，也不会强制打断你。

星光是当下能量；好感是长期关系；今日统计是当天的陪伴记录。三者各有用途，不应把今日次数理解为好感分数。好感称呼与其他日常彩蛋见[首页陪伴系统](../README.md#companion)。

## 9. 常见疑问

| 遇到的情况 | 先这样检查 |
| --- | --- |
| 菜单里找不到“冥想” | 打开聊天输入“冥想”；目前没有独立菜单项 |
| 今日小结不见了 | 鼠标离开按钮试试；悬停提示会暂时占用同一行，今天无计数时也不显示统计 |
| 插电没提醒 | 确认有电池、功能已开、不是首次采样，且不在专注／睡眠中；等下次采样 |
| 喂糖只显示 +10 | 星光接近满格，飘字显示实际增加量而不是固定奖励 |
| 某个动作按钮变灰 | 查看按钮提示的忙碌原因，等当前动作结束 |
| 卡片关闭后不知道怎么退出程序 | 再右键 → 更多 → 退出，或从系统托盘退出 |
| 开启鼠标穿透后点不到角色 | 当前穿透主要影响左键；右键仍可打开设置，托盘也可操作 |
| 表情和展示图不完全相同 | 情绪类别会从关联贴纸里选择，台词、随机数、好感和状态会影响演出 |

更多安装、声音、AI 和数据问题见[安装指南](GUIDE.md)与[聊天助手说明](ASSISTANT.md)。
