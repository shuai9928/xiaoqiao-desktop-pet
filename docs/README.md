## 文档与演示的约定

- 图片下方会说明是源码离线渲染、真实 Tk 界面截图，还是操作流程示意图。
- 界面截图使用虚构的陪伴天数、计数和对话，不包含维护者的个人存档。
- AI 能力与联网条件单独注明；演示生成不调用真实模型。
- 性能取决于电脑、缩放和场景。离线动画统一输出 20 fps，不代表桌宠固定以该帧率运行。
- 本仓库提供源码和素材。生成可执行程序的步骤见安装指南；未经验证的本地安装包不会被当作正式下载链接。
