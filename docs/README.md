## 图片和数据约定

首页图片由当前生产合成器离线生成，使用模拟工作流，额度保持未知；图片内标注“模拟”。它展示静态布局，不是旧设计稿、桌面截图、动态验收或账号接入的证据。

新界面图要说明实际渲染、真实控件或示意图，以及是否采用模拟数据。真实桌面尺寸验收不能被放大图替代。公开文档不放个人聊天、完整代理提示词、真实额度或包含私人桌面内容的截图。
