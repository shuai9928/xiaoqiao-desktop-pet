# AI 与数据说明

[文档导航](README.md) · [安装与使用](GUIDE.md) · [开发指南](DEVELOPMENT.md)

小乔有三个相关但独立的功能：与角色聊天、观察 AI 会话工作流、显示账户额度。一个功能的数据可用，不意味着另外两个已经接通。

## 聊天与本地互动

双击角色、点工作台的“聊聊”，或从右键卡片选择聊天，可打开对话窗。窗口支持输入、发送、阅读历史、选择文本和右键复制；关闭窗口不会清空聊天记录。

顶部快捷按钮用于摸头、喂糖和打开 AI 工作信息。Enter 发送，空白输入不发送；上下方向键可浏览本次窗口的输入历史。长回复请在聊天窗阅读，角色气泡只适合短句。

没有配置模型时，本地角色互动仍可使用。当前核心版集中在聊天、摸头、喂糖、休息／叫醒和场景入口；旧版的系统助手、小游戏、定时工具等不作为当前能力承诺。

自由对话通过 `ai_chat.py` 中配置的 Gemini 服务完成。安装与密钥设置见[使用指南](GUIDE.md#配置自由聊天可选)。配置界面在 Windows 上使用当前用户的 DPAPI 保护密钥；迁到另一台电脑通常需要重新设置。对话和相关记忆可能发送给所配置的模型服务，本机保存不代表模型请求不会联网。

## 工作流：阶段加任务方向

工作台把可取得的公开活动归纳为阅读资料、编写修改、测试验证、审核检查、整理交付等阶段。它尽量合并零碎的读取与命令操作，只补充一层有用方向，例如：

- `编写与修改 · 工作流与进度`
- `测试与验证 · 动态特效`
- `委派子智能体 · 颜色与对比度`

点击 Agent 名字或任务行可以展开。已观察的不同子代理分工会分别显示，但不会复制完整提示词、代理 ID 或隐藏思考。

这些文字是保守的活动摘要，不是任务计划。偶发读文件、等待不应随意改变当前大方向；缺少明确方向时保持概括。委派成功只代表任务发出，不代表代理执行完毕，也不证明实际并行数量。进度点表示已观察阶段，不计算完成百分比。未知的下一步不会被补造。

状态显示按公开记录和新鲜度判断：进行中、等你确认、遇到问题、已结束、空闲或久未更新。同一服务可能有多个本地会话；紧凑实时视图优先展示较新的有效活动，展开后再查看任务。

## 会话从哪里来

| 来源 | 接入机制 | 边界 |
| --- | --- | --- |
| Windows 原生 Codex | `native_session_sync.py` 读取用户目录下的本地会话事件 | 主程序入口自动启动采集；没有日志就没有对应记录 |
| 本地 Claude Code | 同一采集器读取本地项目事件和会话状态 | 不是 Claude 网页或云端开发任务的实时连接 |
| ZCode | 通知／会话 hook，使用 `ai_lights_core.py` 写入清洗后的快照 | 需要 ZCode 一侧已配置相应入口 |
| WSL Codex／Claude | `wsl_lights_hook.py` 等桥接 | 需要额外配置和可达的本机输出路径 |
| Mac Codex／Claude | `mac_session_sync.py` 接收来源快照 | 需要使用者提供同步通道，桌宠不会自动连接另一台电脑 |

采集器不复制原始聊天正文、工具输出、隐藏思考、凭据或账户字段。它使用有限活动标签和真实状态，在本机 `ai_sessions/` 保存工作台快照；缺失或损坏的来源不能阻塞角色渲染。

Claude 云端没有本地日志时，当前仓库没有这类实时会话数据源。把云端代码搬到桌面，或展示 Claude 的共享账户额度，都不能证明云端会话状态已接入。

## 额度从哪里来

当前工作台优先读取 `%LOCALAPPDATA%/AIQuota/usage.json` 的公开用量字段：服务名、周期、已用比例和更新时间。缺少该来源时，其余界面可使用已有 Codex 或 Claude 额度快照；桌宠读取快照，不直接登录所有服务查询账户。

额度条显示的是**已用百分比**。数据缺失显示“暂无数据”或 `—`，过期值标“旧”，不能填成 0% 或 100%。Claude 账户额度可能共享于多个会话，不能归到当前选中的任务。ZCode 会话有状态记录，也不表示 ZCode 额度已接入。

示意图中的数据明确标注“模拟”，只用于验证布局和文字。

## 本地文件

下列文件由程序或接入工具在本机产生，保持原来的运行位置；仓库整理不会把它们迁进 `docs/` 或 `tests/`。

| 文件／目录 | 内容 |
| --- | --- |
| `pet_settings.json` | 大小、声音、位置及其他本地偏好／存档 |
| `chat_history.json` | 与角色的聊天记录 |
| `assets/memories.json` | 角色聊天的长期记忆 |
| `assets/ai_config.json` | 实际服务配置和受保护的密钥字段 |
| `ai_sessions/` | 清洗后的本地工作状态快照 |
| `ai_quota_codex.json` 等来源快照 | 本机账户用量样本 |
| `_tts_cache/` | 回复语音缓存 |
| `pet_cmd.json` | 外部自动化指令 |
| `pet_state.json` | 开启调试状态时的观测结果，可能含聊天文字 |
| `pet_error.log` 等日志 | 本机故障信息 |

旧版保存的数据可能仍在本机，它的存在不表示对应功能仍开放。以上配置、存档、快照、缓存和日志不应上传公开仓库；反馈问题时使用经过脱敏的最小片段。只可公开无密钥的配置示例和明确模拟的演示资料。

## 声音与任务提醒

“声音”是总开关，“朗读回复”控制聊天回复的朗读，“AI 任务提醒”控制会话状态触发的陪伴反馈。它们不会替你批准 AI 的操作，也不会自动回复 Agent。实际语音可用性取决于本机和网络环境。
