# 历史开发工具

[返回当前工具](../README.md)

保留旧补丁、切层、演示、音频制作和Windows辅助脚本，用来回顾生成过程。默认启动和CI均不执行；部分依赖旧素材、方法签名、工作目录或额外依赖，不能直接用作当前修复。

- `cut_*`：曾经失败的切层过程，不重新引入自动切层。
- `_test_ai_quality.py`：会调用真实模型，不进入测试入口。
- `windows/重启小乔.bat`：旧通配重启；当前通过菜单退出旧实例，再正常启动。
- `apply_*`、`prepare_*`：特定旧版本补丁，不适用于当前主程序。
- `render_*`、`fullscreen/`：旧动作演示，不用来宣传现行能力。
- `audio/`：旧音频制作，需要原下载素材。
